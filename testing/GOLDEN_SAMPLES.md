# 골든 샘플 테스트 (Golden Samples)

동일 입력으로 4개 모델을 실행했을 때 **출력 품질을 비교**하기 위한 테스트 가이드입니다.

---

## 목적

- 모델별 강점·약점 파악
- 프롬프트 수정 후 **회귀(regression)** 확인
- 팀 내 "기대 출력 수준" 합의

---

## 테스트 케이스 (권장 3개)

| ID | 프레임워크 | 입력 소스 | 검증 포인트 |
|----|-----------|----------|------------|
| GS-01 | 1-7 SWOT | [examples/sample-input.md](../examples/sample-input.md) D2C 예시 | 4칸 각 4~5항목, 상호작용, 액션 3개 |
| GS-02 | 5-2 보도자료 | sample-input B2B SaaS 예시 | 헤드라인 3안, 5W1H 리드, 포털 최적화 |
| GS-03 | 6-1 GA4 | 아래 고정 입력 | KPI 표, 채널 이상치, 액션 5개 |

### GS-03 고정 입력 (복사용)

```
분석 기간: 2026년 1~3월
비즈니스 목표: 자사몰 매출 +15% YoY
데이터:
- 세션 120,000 / 사용자 85,000 / 전환율 2.1% (전기 2.4%)
- 채널: 오가닉 40%, 유료 35%, 직접 15%, 소셜 10%
- 유료 CPA 전월 대비 +22%, 오가닉 전환율 -0.3%p
- 모바일 이탈률 68%, 데스크톱 42%
주요 캠페인·변경 사항: 2월 결제 UI 개편, 3월 봄 시즌 프로모
```

---

## 실행 절차

1. **Custom Instructions** 적용 ([custom-instructions/](../custom-instructions/))
2. 동일 프롬프트 블록 + 동일 입력을 4모델에 실행
3. [workflows/WORKFLOWS.md](../workflows/WORKFLOWS.md) **출력 품질 검증** 프롬프트로 각 답변 검토
4. 아래 루브릭으로 1~5점 채점

---

## 채점 루브릭 (항목별 1~5)

| 항목 | 5점 | 1점 |
|------|-----|-----|
| **완전성** | 요청 항목 100% 포함 | 절반 이상 누락 |
| **구체성** | 수치·기한·담당 명시 | 모호한 일반론 |
| **논리** | 인과·우선순위 명확 | 비약·모순 |
| **실행성** | 바로 실행 가능한 액션 | 추상적 권고만 |
| **형식** | 표·불릿·제목 구조화 | 장문 나열 |

**합격 기준**: 총점 20/25 이상, 완전성 4점 이상
