# Before / After 예시

플레이스홀더를 **대충 채운 경우**와 **잘 채운 경우**의 차이입니다.

---

## 1-1 MECE 이슈 트리

### Before (품질 낮음)

```
내 문제: [매출이 안 나와요]
```

**예상 문제**: LLM이 일반론·감정 위로에 치우침, 업종 특화 가지 부족

### After (품질 높음)

```
내 문제: D2C 스킨케어 브랜드 '글로우랩'. 자사몰 월 매출 1.2억(전년 동월 1.5억, -20%).
재구매율 28% 유지 중이나 신규 유입 CAC가 3개월 연속 상승(CPA 1.8만→2.4만).
히어로 세럼 1 SKU 매출 비중 62%로 포트폴리오 편중. 2026 H2 올리브영 입점 검토 중이나
자사몰 성장 둔화 원인 규명이 선행 과제.
```

## 2-1 채널 전략

### Before

```
회사: [우리 회사]
마케팅 목표: [매출]
예산: [보통]
```

### After

```
회사/브랜드: B2B HR SaaS 'PeopleFlow', ARR 18억, 타깃 중소기업 50~300인
마케팅 목표: 리드 (무료 체험 신청)
예산 수준: 월 800만 원 (전월 대비 동결)
현재 채널: 검색광고 ROAS 2.1, 링크드인 리드 CPA 9만, SEO 월 유기 1.2만 세션,
이메일 오픈율 22%·전환 0.8%
```

## 5-9 규제·컴플라이언스

### Before

```
검토 문안: [보도자료]
```

### After

```
검토 대상: 보도자료 + 인스타 캡션
업종: 식품 (기능성 표시 없는 일반 건강식품)
검토 문안:
「업계 최초! 2주 만에 확실한 변화, 경쟁사 XX 대비 2배 효과」
(보도자료 본문 전문 붙임)
배포 채널: 네이버 뉴스 배포, 인스타 피드·스토리
특이 사항: 경쟁사명 직접 비교, 임상 데이터 없음, 고객 후기 실명
```
