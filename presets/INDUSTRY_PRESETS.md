# 업종 프리셋 (Industry Presets)

플레이스홀더에 **바로 붙여 넣을 수 있는** 업종별 맥락 문장입니다. 수치는 예시이니 본인 데이터로 교체해 주세요.

---

## 이커머스 / D2C

```
[산업 또는 시장] 국내 D2C 뷰티·생활용품, 자사몰+마켓플레이스 병행
[회사·브랜드·제품명] 자사 브랜드, 월 매출 [ ]억 원, 재구매율 [ ]%
[판매 채널] 자사몰 60%, 쿠팡/네이버 스마트스토어 40%
[마케팅 목표] 신규 고객 확보 / 재구매율 향상 / 객단가 상승 중 택 1
```

**추천 프레임워크**: 3-1 → 3-2 → 2-2 → 2-1

## 사용 팁

1. 프리셋 문장을 해당 프롬프트 `[ ]` 항목에 **복사·수정**해 넣어 주세요.
2. Perplexity 사용 시 업종명·회사명을 **실명에 가깝게** 쓰면 검색 품질이 올라가요.
3. 입력 품질: [guides/INPUT_CHECKLIST.md](../guides/INPUT_CHECKLIST.md)
4. 업종 프리셋 추가 기여는 `CONTRIBUTING.md` 절차를 따라 주세요.
