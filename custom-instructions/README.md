# Custom Instructions (시스템 프롬프트)

각 LLM의 **Custom Instructions / System Prompt** 설정에 붙여 넣을 짧은 지시문입니다.  
모델별 파일을 복사해 해당 도구의 시스템 설정에 저장해 두면, 이 레포의 프레임워크 프롬프트와 함께 쓸 때 일관된 톤·형식을 유지하기 좋아요.

| 모델 | 파일 |
|------|------|
| ChatGPT | [chatgpt.md](chatgpt.md) |
| Claude | [claude.md](claude.md) |
| Gemini | [gemini.md](gemini.md) |
| Perplexity | [perplexity.md](perplexity.md) |

프레임워크 본문은 여전히 `chatgpt/prompts.md` 등에서 **블록 단위**로 복사해 사용해 주세요.
