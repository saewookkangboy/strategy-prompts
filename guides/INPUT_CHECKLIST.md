# 입력 품질 체크리스트 (Part별)

프롬프트 실행 **전** 해당 Part 체크리스트를 확인해 주세요.  
상세 예시: [examples/sample-input.md](../examples/sample-input.md) · [examples/before-after.md](../examples/before-after.md)

---

## 공통 (모든 Part)

- [ ] `[ ]` 항목에 **구체적 수치·날짜·사실**을 넣었어요
- [ ] **의사결정 기한** 또는 **분석 목적**이 명확해요
- [ ] 프레임워크 **1개만** 붙여 넣었어요
- [ ] 이전 단계 LLM 답변을 이어 쓸 때 **전체 맥락**을 포함했어요

---

## Part 1. 전략

- [ ] 문제·산업·경쟁사를 **이름·규모·포지션** 수준으로 적었어요
- [ ] SWOT·경쟁 분석 시 **증거**(매출, 점유율, 고객 수)를 포함했어요
- [ ] 전략 합성(1-12) 전에 **1-1~1-11 중 필요한 분석**을 선행했어요

---

## Part 2. 디지털 마케팅

- [ ] 마케팅 **목표 1개**(인지/리드/매출/리텐션)를 골랐어요
- [ ] **예산 수준** 또는 월 예산 범위를 적었어요
- [ ] 현재 채널 **성과 숫자**(CPA, ROAS 등)가 있으면 함께 넣었어요

---

## Part 3. 커머스

- [ ] **판매 채널**(자사몰/마켓플레이스/소셜) 비중을 적었어요
- [ ] 전환·재구매 **현재 수치**를 넣었어요(없으면 추정치 명시)
- [ ] 프로모·가격 결정의 **목표**(물량/마진/신규)를 명시했어요

---

## Part 4. 기획·아이디어

- [ ] **타깃 오디언스**를 한 문장 페르소나로 적었어요
- [ ] **제약**(예산, 브랜드 가이드, 채널)을 명시했어요
- [ ] 기존 콘셉트·카피 초안이 있으면 함께 붙였어요

---

## Part 5. PR

- [ ] **배포 희망일·매체 유형**(경제지/IT/포털)을 구체화했어요
- [ ] 보도자료용 **검증 가능한 팩트**(날짜, 수치, 인용 가능 인물)를 넣었어요
- [ ] 위기(5-4) 시 **현재 파악된 사실 vs 미확정**을 구분했어요
- [ ] 규제 검토(5-9) 시 **검토 문안 전체**를 붙였어요

---

## Part 6. 데이터·분석·리서치·보고서

- [ ] **분석 기간**과 **비즈니스 목표**를 명시했어요
- [ ] GA4·A/B **원시 수치·표**를 붙였어요(스크린샷 가능)
- [ ] 데이터 **한계**(추적 오류, 샘플 부족)를 알고 있다면 메모했어요
- [ ] 전략 리서치(6-4): **내려야 할 결정**과 **가용 데이터/제약**을 적었어요
- [ ] 마이닝(6-5): **스키마·표·요약 통계**를 붙이고, 없는 수치 생성을 금지했어요
- [ ] 보고서·슬라이드(6-6~9): **수신 대상·분량·브랜드/디자인 제약**을 적었어요

---

## Part 7. 조직·실행

- [ ] **조직 규모·구조**와 **이번 분기 전략 우선순위**를 적었어요
- [ ] OKR(7-1) 시 **상위 전략과의 연결**을 한 줄로 적었어요
- [ ] 변화관리(7-3) 시 **현재 실행이 막히는 지점**을 솔직히 적었어요

---

## Part 8. 부록 (PE · Agent · Fact Checker)

- [ ] **Fact Checker**: 검증 대상 **전문**을 붙였어요 (요약만 넣지 않기)
- [ ] **PE**: 개선할 **현재 프롬프트 전문**과 **실패 패턴**을 적었어요
- [ ] **Agent**: **가용 도구·승인 체계·자동화 금지 항목**을 명시했어요
- [ ] 도메인이 맞는 부록을 골랐어요 (전략=8-1~3, PR=8-13~15 등)
